How to Publish & Share This POS Tool

Zero-backend single-file architecture — deploy in under 2 minutes

Option 1: Offline / Local Office PC (Immediate Use)

Save this file as tupande-cro-pos.html on your office desktop. Double-click to open in Chrome, Edge, or Brave—works 100% offline with automatic browser storage and JSON backups.

Option 2: Netlify Drop (Fastest Free Web URL — 30 Seconds)
  1. Place index.html (renamed from this file) inside a new folder.
  2. Visit app.netlify.com/drop in your browser.
  3. Drag and drop the folder onto the page to get an instant live HTTPS link to bookmark across office devices.
Option 3: GitHub Pages (Permanent Team Hosting)
  1. Create a GitHub repository (e.g., tupande-cro-pos) and upload this file as index.html.
  2. Go to Settings → Pages, select the main branch, and click Save.
  3. Your POS goes live at https://<username>.github.io/tupande-cro-pos/.
Multi-Device Tip: Because data is stored locally in each browser for speed and offline reliability, use the Export Backup (JSON) and Import Backup (JSON) buttons in the Audit Log & Export tab whenever transferring records between office computers.
